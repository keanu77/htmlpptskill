# AGENTS.md：稽核規則（Codex）

你是這份簡報的稽核者，和主筆（Claude）分工。先讀 PLAN.md。

## 你的工作
- **不修改原始檔**（content.js、build.js、styles/）
- 只把發現寫進 `REVIEW.md`；若使用者要求你修正，另開 branch `review-fix-N`

## 檢查清單
1. **連結**：content.js 裡每個網址都能開啟、對應正確工具
2. **QR**：執行 `npm run check`，回報失敗項目
3. **事實**：平台功能、免費方案、工具描述是否正確且未過時；有數字的地方要有依據
4. **一致性**：Lv0–Lv3 名稱、平台名稱、全形標點、頁首 chip 文字
5. **醫療與隱私**：無療效保證、無病人可識別資訊、符合《醫療法》第 85 條精神
6. **版面**：看 `check-output/*.png`，找出字太小、擁擠、對比不足的頁面
7. **離線**：`dist/index.html` 不得載入任何外部資源（搜尋 `http` 開頭的 src、@import）

## REVIEW.md 格式

```
## 第 N 輪（日期）
- [ ] 第 12 頁｜問題：…｜建議：…｜嚴重度：高/中/低
```

使用者會勾選要採納的項目，再交給 Claude 修正。
