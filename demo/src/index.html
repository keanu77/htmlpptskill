開始用

30 秒安裝

# 下載並安裝到你用的 AI coding agent git clone https://github.com/keanu77/htmlpptskill cd htmlpptskill && ./install.sh # 重開 CLI 後直接說 「做一份 HTML 簡報」
支援 Claude Code、Codex CLI、Gemini CLI、Grok Build。需要 Node 20+；QA 用 Playwright，講義用 Python。
